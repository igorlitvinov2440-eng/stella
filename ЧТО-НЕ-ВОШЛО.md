# Что не положили в папку и почему

Здесь всё, что осознанно оставлено за бортом, и как это восстановить.

## 1. `node_modules` — библиотеки

**Почему нет:** сотни мегабайт, скачиваются одной командой. В них ничего своего.

**Как восстановить:**
```powershell
cd код
npm install
```

## 2. Папки сборки `dist`, `dist-new`, `dist-v18`

**Почему нет:** это уже собранные приложения (по 200–400 МБ), их всегда можно собрать
заново из исходников, а от старой сборки только путаница.

**Как восстановить:**
```powershell
cd код
npm run pack:win
```
Результат: `код\dist-new\win-unpacked\Stella.exe`.

## 3. Папка данных `Стелла-данные` — намеренно НЕ включена

**Почему нет:** там личные данные и **ключи доступа** (Fish Audio и другие), история
переписки, задачи Игоря, его тема и настройки. Пересылать это третьей стороне нельзя,
и другой нейронке оно не нужно для работы над кодом.

Что в ней лежит, чтобы вы понимали, где что искать:
- `state.json` — все настройки приложения (тема, фон, задачи, ключи);
- `desktop.json` — режим подложки (Стелла вместо рабочего стола);
- `desktop-log.txt` — журнал шагов этого режима;
- `voices`, `models` — голоса и модели;
- `Служебные файлы окна\` — служебные кэши движка окна.

При запуске на новой машине папка создастся сама и будет заполнена настройками
по умолчанию: обычный фон, стандартная тема, пустой список задач. Режим подложки
тоже будет выключен — его включают в настройках приложения.

## 4. Копии интерфейса (`stella-prototype.backup-*.html`)

**Почему нет:** их около тридцати, каждая по 0,8 МБ (25 МБ шума). Текущий файл
`код\stella-prototype.html` — рабочий, а историю изменений показывают скрипты в
`история-правок\`, в каждом из которых написано, что и зачем менялось.

Если понадобится откат — все копии остались в исходной папке `C:\Stella`.

## 5. Что положили, хотя оно тяжёлое

- `код\vendor\` — 21 МБ: библиотека `transformers.min.js` и модуль
  `ort-wasm-simd-threaded.jsep.wasm`. Это местное распознавание речи; без них
  приложение соберётся, но голосовой ввод работать не будет.
- `образец-дизайна\` — около 35 МБ: картинка образца, десять кадров записи и сама
  запись. Нужны, чтобы понимать, к чему стремимся.

## 6. Чего нет вообще, но оно и не нужно

- Ключи и адреса сторонних сервисов, номер бота в мессенджере, прокси.
- Записи из папок прошлых рабочих сессий (там только промежуточные снимки экрана).
